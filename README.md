# SALUD-01 | Agente de turnos y consultas

Demo estatica e interactiva para GitHub Pages. Simula un agente de turnos y consultas para un centro de salud construido con Copilot Studio y Azure AI Foundry.

## Caso de uso

**Industria:** Salud y Ciencias de la Vida  
**Escenario:** Atencion al paciente  
**Demo:** Agente de turnos y consultas  
**Solucion Microsoft:** Copilot Studio + Azure AI Foundry  
**Valor:** Autogestion de turnos y menor carga administrativa

## Que muestra

1. Preguntas frecuentes administrativas de un centro de salud.
2. Logica de turnos por motivo, cobertura y sede.
3. Simulador de conversacion de paciente.
4. Confirmacion de turno y requisitos previos.
5. Vista operativa de saturacion telefonica y derivaciones.
6. Guardrails: el agente no diagnostica ni indica medicacion.
